1️⃣ The “Blood Sugar Simulator” modal is overlapping incorrectly

The simulator panel is floating on top, but the background screen is still visible and interactive-looking.

You can see:

The Ribeye Steak 12oz page

The ingredients list behind

The simulator panel on top

This creates a visual conflict because the user cannot tell:

Is this a popup?

Is it part of the page?

Should they scroll the background or the panel?

A proper modal should:

Dim the background

Disable interaction behind it

Example expected behavior:

Background → darkened
Simulator → clearly foreground

Right now the background looks half-active.

2️⃣ Text from two layers is colliding

The text “Blood Sugar Simulator” is overlapping the ingredient list underneath.

You can see:

“Dry-aged USDA Choice ribeye”

simulator header

background UI

All stacked visually together.

That means the modal is likely missing proper z-index + backdrop styling.

3️⃣ The CTA (“Unlock Simulation”) is confusing

The button shows:

Unlock Simulation 🔒

But the user already opened the simulator.

So psychologically it feels like:

“Why did you open something I can't use?”

Better flow would be:

Option A (recommended):

Preview Simulation
Unlock Full Simulation

Option B:

Show the result blurred, then unlock.

↓
Popup
↓

Locked feature

Too many layers.

Make the simulator a bottom sheet modal.

Structure:

Meal Page
     ↓
Tap "Blood Sugar Simulator"
     ↓

     ↓
